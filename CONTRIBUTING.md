# Contributing

Thanks for helping improve the dense-to-FTS migration template. To report a bug,
request a feature, or suggest a documentation improvement, please
[file a GitHub issue](https://github.com/pinecone-field/dense-to-fts-migration/issues/new).

Include the following when relevant:

- A clear description of the problem or proposed improvement.
- Steps to reproduce the problem.
- The expected and actual behavior.
- Your Python and Pinecone SDK versions, and the API version the SDK negotiated.
- The migration phase you were in (`export`, `convert`, `import`, `replay`, `reconcile`, ...).
- Relevant logs or error messages with secrets removed.

Before filing, please check the existing issues for a similar report. Never include
API keys, cloud credentials, customer data, or vectors derived from customer data
in an issue.
